# What it is

This is a sandbag project to learn how I can get familiar with Xilinx Zynq 7000 FPGA. The target board is `Cora Z7-07S`, by `Digilent`, purchased from `Akiduki`.

This project is based on a textbook to learn Xilinx FPGA: https://www.shuwasystem.co.jp/book/9784798063263.html

- Board: https://digilent.com/reference/programmable-logic/cora-z7/start
- Marchandiser: https://akizukidenshi.com/catalog/g/g113489/

# Prerequiste

- OS: `Ubuntu22.04LTS`
- Development environment: `Vivado2023.2` and `Vitis2023.2` 
- Development PC: PCs that can run `Vivado` and `Vitis`, usually requires:
    - Storage: Larger than 100GB
    - Memory: Larger than 64GB
